# Python Bank Management System

This project is a simple **Bank Management System** developed using Python.
It demonstrates **Object-Oriented Programming (OOP)** concepts and basic banking operations.

## Features

* Create Bank Account
* Deposit Money
* Withdraw Money
* Check Account Balance

## Technologies Used

* Python
* Jupyter Notebook
* OOP Concepts

## Project Files

* Bank_Management_System.ipynb – Main project notebook
* Bank_Management_System-checkpoint.ipynb – Auto-saved notebook version

## How to Run

1. Open the notebook in Jupyter Notebook or Google Colab.
2. Run all cells.
3. Follow the menu options to perform banking operations.
